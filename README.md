# Portfolio · Hameem Afnan

Personal portfolio, live at **https://4m3n.github.io/Portfolio/**

Hand-built with HTML, CSS and vanilla JavaScript, without frameworks or build steps.

- Bilingual (Spanish / English) with a language toggle that also switches the downloadable CV
- Three colour themes, reveal animations and full support for `prefers-reduced-motion`
- Responsive from 360 px to large desktop screens
- SEO: Open Graph, JSON-LD (`schema.org/Person`), sitemap and canonical URL
- Accessible: skip link, ARIA labels and keyboard navigation

| File | Content |
|---|---|
| `index.html` | Page content (ES text + `data-en` translations) |
| `MiPagina.css` | Styles and themes |
| `MiPagina.js` | Navigation, language/theme switching, animations |
| `_cv-*.html` | Sources used to generate the PDF CVs in `imagenes/` |
